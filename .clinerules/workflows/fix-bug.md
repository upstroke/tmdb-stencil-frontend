# Fix a bug

Use this workflow when the user asks to fix a bug.

1. Read `.clinerules/00-reading.md`.
2. Read the relevant source files.
3. Identify the root cause.
4. Show:
   - Root cause
   - Proposed minimal fix
   - Files to change
   - Verification steps
5. Wait for approval.
6. Implement only the approved change.
7. Show the diff and explain how to verify it.

Do not modify files before approval.
