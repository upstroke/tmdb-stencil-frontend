# Code style

- Follow the patterns already used in nearby files.
- Reuse existing components, helpers, types, routes, and CSS classes.
- Match the surrounding TypeScript, naming, formatting, quotation, and error-handling style.
- Do not introduce a new pattern when an existing one fits.
- Do not refactor unrelated code.
- Do not add comments unless asked.
- Do not create new components, routes, or utilities unless explicitly requested.
